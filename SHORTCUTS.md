# Shortcut guide

Every shortcut Hawkes Math Keys adds to Hawkes Learning's math answer boxes.

Shortcuts work inside any answer box, including inside fractions, roots and brackets.
A shortcut fires the moment you type its last character: the letters you typed disappear and the Hawkes symbol or function appears in their place, exactly as if you had clicked its keypad button.
The Hawkes keypad has to be on the page (it can be minimized) for shortcuts that press its buttons.

## Fractions

| Type | Result |
|---|---|
| `3/4` | 3 over 4 |
| `2x/5` | 2x over 5 |
| `3(x+1)/2` | 3(x+1) over 2 |
| `(x+1)/2` | x+1 over 2 (outer brackets dropped) |
| `/` with nothing before it | Hawkes's normal empty fraction |
| **Alt** + `/` | Hawkes's normal empty fraction, always |

Pressing `/` moves the term just before the cursor to the top of a new fraction and puts the cursor in the bottom box.
The term stops at `+`, `-`, `=`, `<`, `>`, `,`, `*` or a space, so `y=2+3/4` puts only the `3` on top.
Use the **Down** arrow to move between top and bottom yourself, as in normal Hawkes.

## Roots and symbols

| Type | Result |
|---|---|
| `sqrt` | √ square root, cursor inside |
| `pi` | π |
| `inf` | ∞ infinity |

## Comparisons

| Type | Result |
|---|---|
| `<=` | ≤ |
| `>=` | ≥ |
| `!=` | ≠ |

## Greek letters

| Type | Result |
|---|---|
| `alpha` | α |
| `beta` | β |
| `theta` | θ |
| `lambda` | λ |
| `mu` | μ |
| `omega` | ω |

These are the Greek letters on the Hawkes keypad (plus `pi` above).

## Functions

| Type | Result |
|---|---|
| `sin` `cos` `tan` | sine, cosine, tangent |
| `csc` `sec` `cot` | cosecant, secant, cotangent |
| `ln` | natural log |
| `log` | log |

## Inverse trig

| Type | Result |
|---|---|
| `arcsin` | sin⁻¹ |
| `arccos` | cos⁻¹ |
| `arctan` | tan⁻¹ |
| `arccsc` | csc⁻¹ |
| `arcsec` | sec⁻¹ |
| `arccot` | cot⁻¹ |

The extension presses Hawkes's function-with-exponent button, fills the exponent with `-1`, and puts the cursor in the function's argument.
Typing `arcsin` never triggers the plain `sin` shortcut.

## Typing the plain letters

Shortcuts fire as soon as the letters match, so typing the variables `m` and `u` next to each other gives μ.
To keep the plain letters, type a space between them and then delete it: `m`, space, `u`, then remove the space.

## Hawkes's way, for comparison

Without the extension, every symbol, function and Greek letter above means finding and clicking its button on the Hawkes keypad, and fractions must be typed `/` first (`/` `3` Down `4` for 3⁄4).
